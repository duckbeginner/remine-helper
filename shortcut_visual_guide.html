1) 낙관 이미지 설정:
• 🔔 [알림 보기] "낙관(워터마크) 이미지를 선택하세요."
• 🖼️ [사진 선택] (1장 선택)
• 📁 [파일 저장] Shortcuts/watermark.png (덮어쓰기 [ON])
2) 닉네임 & 플랫폼 설정:
• ✏️ [입력 요청] "닉네임 입력" (기본값: 리센느대박) ➔ var_nickname
• 📜 [목록] melon, genie, bugs, vibe
• 📋 [목록에서 선택] ➔ var_platform
3) 자동 잠금 해제 안내:
• 🌐 [URL 열기] prefs:root=DISPLAY&path=AUTOLOCK
• 🔔 [알림 보기] "화면 자동 잠금을 [안 함]으로 변경하셨습니까?"
4) 빌지 입력 및 정규식 파싱:
• ✏️ [입력 요청] "총공 빌지 텍스트를 붙여넣어 주세요"
• 🔍 [일치하는 텍스트 찾기]
(?m)^(\d{1,2}:\d{1,2}) (https?:\/\/[^ ]+) 총공명\s*:\s*([^ ]+) 스밍\s*:\s*([^ ]+)(?: SID\s+M:(\d+)\|G:(\d+)\|B:(\d+)\|N:(\d+))?
5) JSON 큐 생성 & 파일 저장:
• 🔁 [각각 반복] 빌지 블록 분할 ➔ queue_list 생성
• 📚 [사전 생성] 루트 객체 ({ config, queue })
• 📁 [파일 저장] Shortcuts/sming_state.json (덮어쓰기 [ON])
• 🌐 [URL 열기] shortcuts://run-shortcut?name=스밍총공
